# Jar Analyzer — русская локализация

Русский интерфейс программы Jar Analyzer для проверки JAR-файлов Minecraft. Автор оригинальной программы — Winzys. Исходный проект: [winzysss/JarAnalyzer](https://github.com/winzysss/JarAnalyzer). Изменения в этой версии касаются перевода интерфейса и пояснений к результатам; алгоритмы поиска читов не менялись.

## Как пользоваться

1. Скачайте `JarAnalyzer-RU.exe` из релиза этого репозитория.
2. Запустите файл в Windows. Установка Java не требуется: среда выполнения находится внутри `.exe`.
3. Выберите «ПРОВЕРИТЬ ВСЕ ДИСКИ», «Выбрать папку или файл» или «Проверить запущенную Java».
4. Откройте отмеченные файлы и изучите конкретные находки. Сохранить результаты можно кнопкой «Экспорт отчёта».

Программа запрашивает права администратора для быстрой проверки NTFS. Переключить язык можно в меню «Настройки → Язык» или на панели инструментов. Для нового пользователя по умолчанию выбран русский язык.

Результаты проверки — признаки для ручного разбора, а не доказательство нарушения. Обфускация, нативные библиотеки и отдельные совпадения встречаются и в обычных модах.

## Сборка

Нужны Windows и JDK 17 или новее. Сторонние библиотеки уже находятся в папке `lib`.

```powershell
.\build.ps1 -Package -SingleFile
```

Готовый файл появится в `dist\JarAnalyzer.exe`. В релизе он называется `JarAnalyzer-RU.exe`. Содержимое `.exe` создаётся скриптом сборки, который сначала упаковывает приложение и Java, затем делает единый запускаемый файл.
